# D20 v0.14 — Mobile Web + Vercel

## Что изменено

- адаптивный интерфейс для экранов 430–760 px;
- правый постоянный rail контактов на телефоне заменён плавающей кнопкой чатов;
- чат открывается как полноэкранная панель;
- выдвижное левое меню занимает до 88% ширины экрана;
- лента, карточки книг, библиотека, чтение, оценка, профиль и сообщества переведены в одну колонку;
- Book Studio работает на телефоне: toolbar скроллится горизонтально, лист занимает ширину экрана, медиапанель идёт ниже редактора;
- модальные окна открываются как нижние панели;
- WebRTC-звонок использует ширину телефона;
- добавлены safe-area отступы для iPhone;
- добавлен `manifest.webmanifest` и mobile web-app meta tags;
- добавлен `vercel.json` для статической сборки `dist`.

## Локальная проверка

```bash
npm run dev
```

На телефоне `localhost` компьютера не откроется как публичный сайт. Для реального теста между устройствами используйте HTTPS-деплой.

## Vercel

```bash
npm run build
npx vercel@latest
```

При первом запуске:

- Set up and deploy? `Y`
- Scope: ваш аккаунт/команда
- Link to existing project? можно `N` и создать новый проект `d20-platform`
- Directory: `./`

После тестового деплоя:

```bash
npx vercel@latest --prod
```

Vercel выдаст production URL вида `https://d20-platform-....vercel.app`.

## Supabase после публикации

OTP с ручным вводом кода не зависит от redirect URL, но production URL всё равно стоит добавить в Supabase:

`Authentication → URL Configuration → Site URL`

и при необходимости в `Redirect URLs`.

Для камеры/микрофона мобильному браузеру нужен HTTPS. Vercel даёт HTTPS автоматически.
