# FRAKTUM Literature v0.19.1 — Calls UX

- Добавлен входящий FRAKTUM-ringtone: мелодический сигнал повторяется, пока пользователь не примет/отклонит звонок.
- Добавлен исходящий ringback: звонящий слышит гудок до ответа, отклонения, завершения или обрыва связи.
- Звуки генерируются через Web Audio API и не требуют внешнего аудиофайла.
- Добавлен opt-in для браузерных уведомлений о звонках в разделе сообщений.
- При входящем звонке браузер показывает системное уведомление, если разрешение уже выдано.
- Добавлена серверная запись `call` в `lit_notifications` при создании звонка; уведомление привязано к соответствующему диалогу.
- Уведомления не создаются инициатору звонка и учитывают `notification_mode = mute`.

Ограничение Web/PWA: если браузер полностью закрыт, обычный polling не работает. Для звонка при полностью закрытом сайте нужен отдельный Web Push/нативный push-слой.
