# FRAKTUM Literature v0.17.0

Closed Beta Candidate литературной платформы FRAKTUM.

Главная часть этой сборки — **Free Canvas Book Studio**: книжная страница теперь работает как реальный лист/дневник, а не как Word с картинкой внутри строки.

## Быстрый запуск

```bash
npm run dev
```

Production build:

```bash
npm run build
```

Vercel использует `vercel.json` и публикует `dist/`.

## Book Studio v0.17

В режиме `Книга` доступны:

- свободные текстовые блоки;
- свободные фото-объекты;
- drag & drop в любую точку страницы;
- произвольный размер;
- поворот;
- порядок слоёв;
- блокировка объектов;
- цвет бумаги и базовый цвет текста;
- фото-фон страницы;
- несколько фото поверх фоновой обложки;
- цветные заметки;
- автоматическое обтекание текста вокруг фотографий;
- загрузка, drag & drop и вставка изображений из clipboard;
- точный Preview и Reader на основе того же canvas-макета;
- книжное перелистывание страниц.

Старый режим `Документ` сохранён для обычной линейной работы с текстом.
